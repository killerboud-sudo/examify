# منشئ الاختبارات (Examify)
Next.js 15 + Vercel AI SDK. صورة اختبار → JSON منظَّم → محرر + معاينة → طباعة PDF.

## تشغيل
```
npm install
cp .env.example .env.local   # أضف مفتاحًا واحدًا على الأقل
npm run dev
```
## النشر على Vercel
ارفع المستودع، ثم أضف متغيرات البيئة (نفس أسماء `.env.example`) من إعدادات المشروع.

## البنية (للتوسّع)
- `src/lib/schema.ts` — مصدر الحقيقة الوحيد لشكل الاختبار (Zod). كل الميزات تقرأ وتكتب هذا الشكل.
- `src/lib/ai/providers.ts` — مزوّد جديد = سطر واحد.
- `src/lib/ai/extract.ts` — تعليمات الاستخراج.
- `src/lib/figures/registry.tsx` — شكل هندسي جديد = عنصر واحد (دالة رسم + قيم افتراضية).
- `src/components/` — المحرر والمعاينة.
- الخطوات التالية المقترحة: تصدير Word (`/api/export/docx`)، حفظ الاختبارات (قاعدة بيانات)، حسابات المستخدمين، قوالب تصميم متعددة.
